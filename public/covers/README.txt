COVER ART — drop-in instructions
================================
Save each book's cover from its Amazon product page and place it in this
folder using these exact names (JPG format):

  sd-01.jpg  Sleeping Dogs: The Awakening
  sd-02.jpg  Endangered Species
  sd-03.jpg  The Year of the Dog
  sd-04.jpg  The Dogs of War
  sd-05.jpg  A Deadlier Breed
  sd-06.jpg  The Devil's Litter
  sd-07.jpg  The People's Republic of America
  sd-08.jpg  Spare Me, Kill the Rest

Then re-zip the whole site folder and drag it onto the Netlify Deploys page.
Each book's file page will show the real jacket automatically — no code
changes needed. Missing covers fall back to the styled placeholder.
